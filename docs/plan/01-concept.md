# コンセプト: TraceEffect

## 目的

私たちは、暗い星空を自分の船で飛びたい人の、撃っても景色が反応しない不満を、光を短く撃って断つほど背景が厚くなり目的の星の最接近が大きくなる一本の飛行で解決する。

誰が遊んでいる状況: ブラウザで、音なしの暗い星空を、自分の宇宙船の少し背後から飛んでいる。

## 感情

- 主: 感覚。背景の光と色が、撃った直後に変わる快さ
- 従: 挑戦。連続で断つほど、その背景が厚くなる
- 主動詞がそれをどう作るか: 光を断つたびに跡が背景へ残り、外すか被弾すると厚みが一段戻る

## 10秒

プレイヤーは光を短く撃って断つ。1周の終わりに背景が一段厚くなり、すぐに次の光が来る。

手元の絵: 宇宙船の少し背後から、暗い星空の前方から飛来する光弾を撃ち、断った場所の粒子が背景に残る。

## ジャンル

- 呼び方: 背後視点の宇宙シューティング
- 土台にする既知の気持ちよさ: 船が前へ進み、短く撃つと結果がすぐ分かること。残機があること
- 足すルール（1つか2つ）: 断った光が背景の星空に残り、その厚みが、約90秒後に最接近する一つの星の光の大きさになる

## ループ

- 短: 照準して撃つ。断たれれば背景が厚くなり、次の光が来る。被弾すると残機が1減り、厚みも一段戻る
- 中: 前方の一つの星へ約90秒飛び、最接近で終わる。残っている厚みが高いほど、その光が大きい。残機がゼロなら手前で終わる
- 長: 残さない。次の飛行に厚みも残機も持ち越さない

## ピラー

採否は、この3つだけを見る。中身は一つの飛行を、切るとき用に分けたもの。

1. 撃った結果は、すぐ背景に残る
2. 連続の厚みは背景だけが持ち、最接近の光の大きさになる
3. 音も、機体の見た目の変化も、セーブも足さない

## 縦スライスで証明すること

最初の一本に、90秒、残機3、目的の星への最接近までを入れる。飛来する光弾は1種類、プレイヤー弾は1種類。

証明すること: 撃つと背景が厚くなり、被弾で残機と厚みが戻り、目的の星の最接近がその厚みで大きくなること。

入れないもの: ボス、二本目、音、機体の見た目の変化、セーブ、撃つ以外の一手。
