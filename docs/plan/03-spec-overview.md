# 概要仕様: TraceEffect

この仕様の狙い: 撃っても景色が反応しない不満を、背景の厚みで解く。実装で迷ったら、宇宙船の見た目や音ではなく、背景が変わる方を優先する。

## 範囲

- 誰が: ブラウザで、暗い星空を自分の船で飛ぶ人
- 何のために: 撃った結果が背景に残ることを、一本の飛行で確かめる
- どこまでを: 約90秒で前方の一つの星に最接近するところまで。残機がゼロならその手前で終わる
- どう遊ぶか: 船の少し背後から見て、前方から飛来する光弾を短く撃って断つ。連続すると背景の粒子が厚くなり、最接近の光が大きくなる

## ゲームサイクル

照準して撃つ → 光が断たれて背景に残る → 厚みが一段上がる → 次の光が前に現れる。

被弾する → 残機が1減る → 厚みが一段戻る → 残機が残っていれば飛行を続ける。残機が0なら、最接近の前に終わる。

約90秒で星に最接近する → そのときの厚みに応じた光が出て終わる → 次の飛行へは何も残さない。

## 画面フロー

画面は飛行の一つにまとめる。タイトルも結果も、別画面に分けない。

- 飛行: 船、星空、前方の星、飛来する光弾、残機が見える。ここで照準して撃つ
- 同じ画面の終わり: 最接近の光、または残機0で止まった状態。もう一度始める判断だけをする

## 続ける理由

一本のあいだだけ。序盤は薄い星空で、断つと背景がすぐ変わる。連続すると厚みが残り、最後の星の光がご褒美になる。被弾はその厚みを一段戻す。終わったら最初の薄さに戻って、同じ一本をもう一度飛ぶ。

## 縦スライスの境界

含むもの: 背後からの宇宙船、暗い星空、飛来する光弾1種類、プレイヤー弾1種類、残機3、厚み、約90秒、目的の星への最接近。

やらないもの: ボス、二本目、音、機体の見た目の変化、セーブ、サーバー、ロックオン、ボム、撃破数。
