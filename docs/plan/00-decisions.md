# 決定ログ

- 状態: プロジェクト開始
- ゲーム名: TraceEffect
- プロジェクト: /Users/ikegayayuuki/workspace/trace-effect
- ゴール: 自分で気持ちよさを確かめる短い試作
- 制約: 1人。ブラウザ。Three.js と Blender。音は出さない。サーバーにもセーブにも書かず、プレイ中の状態はメモリだけ。期間の日付は未決
- 目的一文: 私たちは、暗い星空を自分の船で飛びたい人の、撃っても景色が反応しない不満を、光を短く撃って断つほど背景が厚くなり目的の星の最接近が大きくなる一本の飛行で解決する
- 感情: 主は感覚 / 従は挑戦（連続で決める）
- 動詞: 光を短く撃って断つ
- ジャンル: シューティング。宇宙船を少し背後から見る。暗い星空
- 短いループ: 照準して撃つ → 光が断たれ背景に残る → 厚みが上がる → 次の光が来る。被弾すると残機が1減り、厚みも一段戻る
- 中ループ: 前方の一つの星へ約90秒。最接近で終わる。残っている厚みが高いほど、その光が大きい。残機0なら手前で終わる
- 長いループ: 残さない
- 土台: 背後から見る宇宙船が前へ進み、短く撃つと結果がすぐ分かること
- 差分: 断った光が背景の星空に残り、その厚みが目的の星の最接近の大きさになる。宇宙船の見た目では派手さを出さない
- ピラー: 撃った結果はすぐ背景に残る / 連続の厚みは背景だけが持ち、最接近の光の大きさになる / 音も、機体の見た目の変化も、セーブも足さない
- 縦スライス: 最初の一本に、90秒、残機3、目的の星への最接近までを入れる。光の筋は1種類、弾は1種類。ボス、二本目、音、機体の変形、セーブは入れない
- 収益: 対象外
