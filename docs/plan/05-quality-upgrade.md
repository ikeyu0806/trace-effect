# 品質向上: 現行世代の表現と武装・アイテム・残機

2026-10-08の依頼で、縦スライス（PS1相当の素朴な見た目、隕石1種、武器1種）を、PS4/PS5世代の表現密度と遊びの幅へ引き上げる。00〜04の「やらない」のうち、武装強化、ボム、2種類目の飛来物、スコア表示はこの文書で解禁する。音とセーブは引き続き入れない。

## 狙い

- 撃った結果がすぐ背景へ残る、というピラーは維持する。撃破で背景の星の厚みが増え、最接近の光が大きくなる仕組みもそのまま残す。
- その上に、アイテムで武器が変わる手触りと、残機・シールドで粘る緊張を足す。
- 見た目は、近景の機体と飛来物はBlenderで作った細かいhard-surfaceモデル、遠景は惑星・環・オーロラ・星雲で埋める。

## 残機

- 初期3、最大5。被弾すると残機−1、厚み−1、武器Lv−1（Lv1ならSPREADへ戻る）、コンボ消失、2.4秒の無敵（機体が点滅）。
- シールド中の被弾はシールドだけが割れ、1秒の無敵。
- 20,000点、50,000点、以後50,000点ごとに1UP。
- 0で終了。最接近は残機が残っていたときだけ。

## 得点

小岩100、中岩200、大岩400、宇宙ゴミ300、結晶岩500。2秒以内の連続撃破でコンボが続き、5コンボごとに倍率+0.5（最大×4）。

## 出現

90秒のあいだに出現間隔を約1.1秒から0.5秒へ縮め、同時数も増やす。結晶岩は約11秒ごとに出る高得点の標的。アイテムは飛来物から落とさず、約6.5秒ごとに単体で、隕石より遅く自機の届く範囲を通るように流す。

避けるもの（灰色の岩・金属片）と取るもの（色付きで発光するemblem）を輝度と形で分け、さらに約2.6秒以内に自機へ当たる軌道の飛来物を赤い警告枠で囲む。カメラはやや高い位置から見下ろし、黄道面の塵と接触影で上下を読ませる。

## 旅程

90秒のあいだに、環上（Cassini的な環の上）→氷衛星の航跡→小惑星帯→散光星雲→目的星へ、光源・霧・遠景の惑星位置が移る。新しいGLBは足さず、既存モデルの流用と手続きの遠景でCloudflare無料枠（ファイル25MiB）に収める。
