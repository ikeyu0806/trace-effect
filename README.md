# TraceEffect

土星型のガス惑星とオーロラの見える宙域を、宇宙船の少し背後から90秒飛ぶシューティング。隕石と宇宙デブリを撃ち抜き、単体で流れてくるアイテムで武器を切り替えながら、前方の一つの星へ最接近する。音は出さない。

計画は [docs/plan](docs/plan/) にある。

## 遊び方

- `npm install`
- `npm run dev`
- 表示されたローカルURLをブラウザで開く

| 操作 | キーボード | マウス |
| --- | --- | --- |
| 移動 | 矢印キー / WASD | ポインタ移動 |
| 射撃 | Space長押し | 左ボタン長押し |
| NOVA | B / Shift | 右クリック |
| 一時停止 | Esc | — |

### 武器

アイテムを取ると武器が切り替わる。同じ武器を重ねるとLV3まで強くなり、LV3でさらに取ると1000点。被弾するとLVが1つ下がり、LV1で被弾するとSPREADへ戻る。

- SPREAD: 中央と周囲へ広がる拡散パルス。LVで弾数と広がりが増える
- HOMING: 翼下ポッドから追尾ミサイルを連射し、別々の標的を狙う
- LASER: 押している間、照準方向へ貫通ビームを照射する
- WAVE: 広がりながら進み、触れたものをまとめて貫く環状波
- THUNDER: 最寄りの標的から近くの標的へ次々に連鎖する雷撃

### アイテムと残機

- SHIELD: 被弾を1回だけ防ぐ
- 1UP: 残機+1（最大5）
- NOVA: ストック+1（最大3）。使うと衝撃波で周囲の飛来物をすべて破壊する
- OVERDRIVE: 8秒間、連射速度が上がる

残機は3から始まり、20000点と50000点、その後は50000点ごとに1機増える。被弾後は約2.4秒無敵になる。アイテムは約6.5秒ごとに単体で流れてくる。効果ごとに形の違う発光emblem（THUNDERは稲妻、SHIELDは盾など）と名前タグで示し、自機へ当たる軌道の隕石・デブリには赤い警告枠が付く。大きな隕石は割れて小さな隕石になる。連続撃破でコンボ倍率（最大4倍）が上がる。90秒を飛び切ると、残機1機につき3000点のボーナスが入る。結果画面の「スコアをポスト」から、スコアと撃破数をXへ投稿できる。

## 3Dモデル

`public/models/` のGLBは、[blender-works](../blender-works) のスクリプトで生成し、検査済みの成果物をmeshopt圧縮して取り込んだもの。

| ファイル | 内容 |
| --- | --- |
| `trace_fighter_mk2.glb` | プレイヤー機。噴射口・砲口・ミサイル・翼端のsocketを持つ |
| `asteroid_set.glb` | 頂点色付きの隕石4種と結晶隕石 |
| `space_debris_set.glb` | 衛星、燃料タンク、トラス、外板、太陽電池片、ロケット段 |
| `trace_pickups.glb` | 効果ごとの記号を持つアイテムemblem9種と追尾ミサイル |

blender-worksでモデルを作り直したら、次で取り込み直す。

```sh
scripts/sync-models.sh
```
